🎓 Java Course Registration System
A console-based Course Registration System built in Java as part of the CodSoft internship tasks. This application models a university registration portal using Object-Oriented Programming (OOP) principles, featuring a robust course database, student records, slot management, and seamless registration/drop capabilities.

🚀 Features
Course Database (Course): Stores essential course information including course code, title, description, capacity, enrolled counts, and meeting schedules.

Student Database (Student): Manages individual student profiles, student IDs, names, and a dynamic list of currently registered courses.

Course Listing (displayCourseListing): Displays all available courses along with their real-time slot availability and capacity metrics.

Student Registration (registerCourse): Allows students to sign up for courses securely while checking against maximum capacity limits and duplicate registrations.

Course Removal (dropCourse): Enables students to drop classes they have previously registered for, automatically freeing up slots in the course database.

Interactive Console UI: Features clean menus with pause prompts (Press Enter to continue...) to ensure real-time transaction results are easily readable.*/
